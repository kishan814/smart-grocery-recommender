# Smart Grocery Recommender

An AI-powered smart grocery recommendation website built using HTML, CSS, and JavaScript.

## Features

- Smart grocery recommendations
- Product search
- Grocery categories
- Shopping cart functionality
- Total bill calculation
- Health-related grocery suggestions
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AI-based recommendation concepts

## Project Purpose

This project was developed as an educational project to create a smart grocery shopping experience with recommendation and health-focused features.
